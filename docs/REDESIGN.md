# 再設計の実装・検証記録

## 承認済みの方針

ReAPI・CSWMを維持し、OciXCromのXP・ランク管理を独立化する。既存のゲームバランスとアセットを維持し、旧XPとBF4カウンタを新しい保存先へ移行する。本番の停止・切替はこの作業に含めない。

## 作業台帳

1. 変更前のソース・アセット・差分を公開対象外のローカルバックアップへ退避。
2. 兵科・武器管理、ランク・保存、移行ツールを分担実装し、相互レビューと親側の統合確認を実施。
3. コンパイラを発見。AMX Mod X 1.10.3-A.K。ReAPIは公式コミット `4516d1efdfd8a686a66c191c441981b720b0a7c5` を検証用に固定。
4. OciXCrom移行元の参照ソースは公式コミット `70f9f37c1073d8b367cc014c65483b83baebec50`。実サーバーの導入版・実データとの一致は別途確認が必要。
5. 全41武器のV2登録、実コードを使うPawnテスト、移行工程間テストを追加。検証結果と未実施項目は `VERIFICATION.md` を参照。

## 判断記録

- 元の作業ツリーに既存の変更があるため、同じ作業ツリーで既存変更を保持し、退避コピーを比較元にする。
- 新保存先は旧領域と分離する。プレイヤーキーは `steam:` / `nick:` / `ip:` を明示する。
- BF4旧カウンタの後半19値は「メダル数」ではなく獲得リボン数。元の値と閾値計算を保持する。
- 地雷の判定間隔はゲーム内測定なしに変更しない。まずトレースハンドルの生成・解放回数を削減する。
- 設定されたヘッドショット報酬とBF4独自ボーナスは別理由として両方保持し、既存の合計値を変更しない。HUDの待ち時間だけを付与処理から切り離す。

## 検証の区分

コンパイル、オフライン移行テスト、ゲーム内受入、負荷測定を分けて記録する。コンパイル成功を実サーバーのロード・ゲーム動作の証明として扱わない。
